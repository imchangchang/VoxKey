VoxKey

按住说，松手出字

按下键盘上的语音键说话，松开手，文字直接进当前光标。 不上剪贴板、不弹输入框。识别全部在本机完成，音频不上传。

macOS（Apple 芯片）
需要 macOS 12 或更新版本 · arm64
下载
Windows · 计划中 Linux · 计划中

装好之后

  1. 把 VoxKey.app 拖进「应用程序」，双击打开。
  2. 它会先下载识别模型（约 800MB，首次一次性，之后不再下）。悬浮条上能看到进度。
  3. 按提示授权三项权限：
    • 麦克风 — 录音
    • 辅助功能 — 把文字写进当前输入框
    • 输入监控 — 读设备发来的按键
  4. 按设备上的语音键说话，松手上屏。菜单栏图标里可以暂停、手动开始、看状态。
第一次打开被系统拦下？未签名的版本会提示「无法验证开发者」。 在「系统设置 → 隐私与安全性」里点「仍要打开」，或者右键点 App 图标选「打开」。 只需要放行一次。

出问题了

日志在 ~/Library/Logs/VoxKey/voxkey.log，启动时也会把路径打进日志。 报问题请带上它，以及 开一个 issue。
